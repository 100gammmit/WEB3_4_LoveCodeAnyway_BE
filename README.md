# 또방 (Ddobang) - 백엔드 서버

## 1. 프로젝트 소개
'또방'은 방탈출 매니아를 위한 통합 플랫폼 입니다. 실제 방탈출 매니아의 수요를 조사하여, 방탈출 정보 탐색, 방탈출 모임 모집, 개인 방탈출 일지 작성 등 방탈출과 관련된 다양한 기능을 제공합니다. </br>
본 프로젝트는 웹 사이트 '또방'의 백엔드 서버를 담당합니다.

## 2. 핵심 도메인

본 프로젝트는 여러 하위 도메인으로 구성되어 있으며, 각 도메인은 특정 비즈니스 로직을 책임집니다.

- **`member`**: 사용자 계정, 프로필, 인증 및 권한 부여 등 회원 관련 모든 기능을 관리합니다.
- **`party`**: 사용자들이 생성하는 '파티'(일회성 방탈출 모임)을 관리합니다. 모임 생성, 참여, 조회 및 상태 변경 등의 로직을 포함합니다.
- **`diary`**: 사용자가 작성하는 '다이어리'(방탈출 일지)를 관리합니다. 사용자가 경험한 방탈출의 후기, 평가 등을 기록하고 조회하는 등의 기능을 제공합니다.
- **`region`**: '지역' 정보를 관리합니다. 사용자가 지역별로 방탈출 카페 및 테마를 탐색할 수 있도록 지원합니다.
- **`store`**: 스토어(방탈출 카페) 정보를 관리합니다. 카페의 위치, 연락처, 운영 시간 등 기본 정보를 포함합니다.
- **`theme` & `tag`**: 방탈출 카페에서 제공하는 '테마'(개별 방탈출 게임) 및 테마를 구분하는 '태그'를 관리합니다. 이 도메인들은 테마의 세부 정보, 테마 검색 기능 등을 담당합니다.
- **`themewish`**: 사용자가 관심 있는 테마를 '찜'할 수 있는 기능을 제공합니다.
- **`message`**: 사용자 간의 쪽지 기능을 담당합니다.
- **`alarm`**: 새로운 메시지, 모임 관리 등 사용자에게 전달되어야 할 알림을 생성하고 관리합니다.
- **`board`**: 관리자에게 문의 사항을 전달하는 '1:1 문의 게시판' 기능을 담당합니다.
- **`upload`**: 다이어리, 프로필 등에 사용될 이미지 및 파일 업로드를 처리합니다.

## 3. 폴더 구조

```
├── src
│   ├── main
│   │   ├── java
│   │   │   └── com/ddobang/backend
│   │   │       ├── domain        # 비즈니스 로직을 담는 도메인 패키지
│   │   │       │   │   ├── controller
│   │   │       │   │   ├── service
│   │   │       │   │   ├── repository
│   │   │       │   │   ├── entity
│   │   │       │   │   └── dto
│   │   │       └── global        # 전역적으로 사용되는 모듈
│   │   │           ├── auth
│   │   │           ├── config
│   │   │           ├── exception
│   │   │           └── security
│   │   └── resources     # 정적 리소스 및 설정 파일
│   └── test              # 테스트 코드
├── infra                 # Terraform을 사용한 인프라 관리 코드
```

## 4. 기술 스택

- **Framework**: Spring Boot, Spring Security
- **Language**: Java
- **Build Tool**: Gradle
- **Database**: MySQL, H2(only for tests)
- **Storage**: AWS S3 for file storage
- **Containerization**: Docker

## 6. 인프라 (Infrastructure)

인프라 관리는 Terraform을 사용하여 코드형 인프라(IaC)로 관리됩니다. 이를 통해 인프라 구성의 일관성을 유지하고, 변경 사항을 추적하며, 자동화된 배포 파이프라인을 구축합니다. 각 서비스는 Docker 컨테이너 위에서 동작하여 개발 및 배포 환경의 통일성을 보장합니다.
